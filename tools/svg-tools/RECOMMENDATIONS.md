### Converter

#### ImageMagick

- **Rank 2 of 32** | score 9.00 (base 9, uses never logged) | id `imagemagick`
- **Verification:** verified, partly secondary - re-check; verified on 2026-11-04. primary for licence and delegate wiring (GitHub raw LICENSE, config/delegates.xml.in, configure.ac); secondary for renderer-quality ranking and policy behaviour.
- **Good for:** Batch rasterising SVG to PNG/JPG/WebP and general bitmap post-processing from the CLI (`magick in.svg out.png`); not an SVG editor.
- **Links:** [homepage](https://imagemagick.org/) | repo: https://github.com/ImageMagick/ImageMagick | [evidence](https://raw.githubusercontent.com/ImageMagick/ImageMagick/main/config/delegates.xml.in)
- **License:** ImageMagick License (permissive, Apache-2.0-like, GPLv3-compatible; no SPDX id in the file I read) | open source: yes | price: free
- **Install:** brew install imagemagick | apt install imagemagick (CLI is `magick`; IM6 packages on older distros use `convert`)
- **SVG notes:** SVG is decoded by one of three back-ends, picked by how the build was configured: (1) the `svg` delegate in delegates.xml, which shells out to `rsvg-convert` (librsvg), (2) an Inkscape delegate (`svg:decode`, uses `inkscape --export-filename`), or (3) the built-in MSVG/XML renderer (SVG -> MVG). Source builds default to `--with-rsvg=no` (configure.ac), so a self-built binary falls back to MSVG unless librsvg is requested. Run `magick -list format | grep -i svg` and `magick -list delegate` to see what your install uses. Community guidance (forum, secondary) ranks quality Inkscape > RSVG > MSVG; MSVG is weakest (CSS, filters, text).
- **Caveats:** Security: ImageMagick has a long CVE history in SVG/MVG/MSL and URL/delegate handling. Never feed it untrusted SVG without a restrictive policy.xml (disable MVG/MSL/URL/HTTPS coders, limit resources). Distro default policy files are 'open' and meant for trusted/sandboxed use. For local dev with your own files this is fine. A policy can block SVG outright (users hit 'not authorized' errors). If you only need SVG -> PNG, resvg or rsvg-convert are more predictable. Current release number NOT verified (a Cygwin announcement from Dec 2025 lists 7.1.2.3).
